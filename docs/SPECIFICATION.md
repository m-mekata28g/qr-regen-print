# 仕様書

機能、画面、業務ルールの仕様です。ルールには番号（BR-xx）を付けており、[TEST_PLAN.md](TEST_PLAN.md) のテスト項目から参照しています。

- 構成・データの流れ：[SYSTEM_OVERVIEW.md](SYSTEM_OVERVIEW.md)
- データ項目・形式：[DATA_DESIGN.md](DATA_DESIGN.md)

## 1. 用語

| 用語 | 意味 |
|---|---|
| QRコード | 納品に使うQRコード。内容は、URLの文字列 |
| URL一覧 | 読み取ったURLを、1行に1件ずつ並べたテキスト（TXTファイル） |
| 本店名 | ホールを束ねる親の名称。ホール名の候補を絞り込むために使う |
| ホール名 | 納品先の名称。印刷対象の絞り込みに使う（印刷では必須） |
| 納品日 | 納品する日付 |
| 商品名 | QRコードの下に印刷する文字 |
| ラベル | 納品日・本店名・ホール名・商品名の4項目 |
| 未印刷 / 印刷済み | PC側のQRコードの状態。PDFを作成すると、対象が印刷済みになる |
| 送信済み | スマートフォン側で、メール送信に成功したURLの状態 |

## 2. 全体の流れ

| 手順 | 画面 | 作業 |
|---|---|---|
| 1 | ① | QRコードを読み取る |
| 2 | ① | 送信するURLを確認し、選択する |
| 3 | ① | 選択したURLをメールで送信する |
| 4 | ② | 送信済みURLを確認する。必要なら手順2へ戻す |
| 5 | ③ | URL一覧（TXT）を読み込み、QRコードを生成する |
| 6 | ③ | ラベル（納品日・本店名・ホール名・商品名）を付与する |
| 7 | ④ | ホール名と納品日で絞り込み、印刷するQRを選んでPDFを作成する |
| 8 | ⑤ | 印刷済みのQRをホール別に確認する。必要なら手順7へ戻す |

## 3. 画面仕様

### 3.1 共通

| 項目 | 仕様 |
|---|---|
| メニュー | ①〜⑤と「⚙ 設定」を横一列に表示する。幅が足りないときは横スクロールする |
| 選択中のメニュー | 黒、それ以外は薄いグレー（`#e5e7eb`） |
| 部品の警告 | jsQR、jsPDF、qrcode-generator のどれかを読み込めないとき、画面上部に赤い警告と「再読み込み」ボタンを表示する |
| 状態表示 | 塗りつぶしではなく、左に細い線を付けた文字で表示する。成功は緑、注意は橙、エラーは赤 |
| 「全選択」「選択解除」 | すべての画面で、同じ薄いグレー（`#e5e7eb`）のボタンにする |
| 件数表示 | 一覧ごとに、件数と選択数を、一覧の上に表示する |
| 一覧が空のとき | 一覧の場所に、そこに何が表示されるかを説明する文章を表示する（例：「今回読み込んだURLはここに表示されます。」） |
| 絞り込みの初期値 | 絞り込みの条件を指定しないときは、「すべて表示」と表示する（④のホール名は必須のため、「ホール名を選択」） |

### 3.2 ① QRコード読取 / URL送信（手順1〜3）

**手順1：QRコード読取**

| 項目 | 仕様 |
|---|---|
| 操作 | 「スキャン開始」「停止」 |
| 検出 | カメラ画面全体から、QRコードを自動で検出する。複数のQRコードが同時に写っていても、すべて処理する |
| 検出中の表示 | QRコードの周囲に枠を表示する。緑は保存、橙は登録済み、赤はURL以外 |
| 保存時の通知 | 画面上部の表示、音、振動 |
| 画面上の情報 | 状態バッジ（探索中・保存しました・登録済み・URL以外）、「今回 〇件」、検出中のURLの文字 |
| 補助 | 対応する端末では、ライトのON/OFFと拡大を操作できる。連続オートフォーカスを要求する |
| 停止時の表示 | `読み取り完了：追加 〇件 / 重複 〇件 / 読み取り不可 〇件` |
| 自動停止 | 別の画面へ移ったときと、アプリが裏に回ったときに、カメラを止める |

**手順2：URL確認**

| 項目 | 仕様 |
|---|---|
| 一覧 | 今回読み込んで、まだ送信していないURLを、新しい順に表示する。番号、URL、読み取り時刻（`読み取り：2026/10/9 16:11:48` の形式）、「未送信」の表示を並べる |
| 選択 | 行のどこをタップしても、選択と解除ができる |
| ボタン | 「全選択」「選択解除」「選択URL削除」 |
| 表示 | 「全 〇件 / 選択 〇件」 |
| URLの改行 | `/ ? & = #` の位置で改行する |
| 保存 | 一覧は、アプリを閉じても残る |

**手順3：URL送信**

| 項目 | 仕様 |
|---|---|
| ボタン | 「URL送信」、「GAS接続テスト」 |
| 送信ボタンの表示 | 選択がなければ「URL送信」、選択があれば「URL送信（〇件）」 |
| 設定の状態 | 設定済みなら「Gmail移行設定済み」、そうでなければ「未設定」 |
| 結果の表示 | 送信完了、失敗の理由、応答を確認できなかった旨を表示する |

### 3.3 ② 送信済み（手順4）

| 項目 | 仕様 |
|---|---|
| 一覧 | 送信から24時間以内のURLを、送信が新しい順に表示する。URLごとに、読み取り時刻と送信時刻（`送信：2026/10/9 16:11:48` の形式）を表示する |
| ボタン | 「手順2に戻す」（選択があれば「手順2に戻す（〇件）」）、「全選択」、「選択解除」 |
| 差し戻し | 選んだURLを、手順2の一覧へ戻す。メールが届かなかったときなどに、再送信するために使う |
| 自動消去 | 送信から24時間たつと、一覧から消える |
| 件数 | `全 〇件 / 選択 〇件` |
| 一覧が空のとき | 「送信後24時間以内のURL履歴はここに表示されます。」を表示する |

### 3.4 ③ QRコード生成 / ラベル付与（手順5〜6）

**手順5：QRコード生成**

| 項目 | 仕様 |
|---|---|
| ボタン | 「URL一覧を一括読込」 |
| 入力 | `.txt` または `.csv`。複数ファイルを同時に選べる |
| 処理 | URLごとにQRコード画像を生成して保存する。同じURLは登録しない |
| 結果の表示 | `読み込み完了：追加 〇件 / 重複 〇件 / 読み取り不可 〇件` |

**手順6：ラベルの付与**

| 項目 | 仕様 |
|---|---|
| 入力 | 納品日（日付）、本店名（選択）、ホール名（選択）、商品名（入力。過去に使った商品名を候補に表示） |
| ホール名の候補 | 先に本店名を選ぶと、その本店に登録されたホール名だけが候補に出る |
| 付与ボタン | 「選択QRに納品日を付与」「選択QRに本店名を付与」「選択QRにホール名を付与」「選択QRに商品名を付与」。それぞれ、その項目だけを付与する |
| その他のボタン | 「全選択」「選択解除」「選択QR削除」「選択QRのラベルを消去」 |
| 絞り込み（未入力） | 納品日／本店名／ホール名／商品名のうち、選んだ項目が未入力のQRだけを表示する。1項目ずつ選ぶ。付与後も、選んだ条件は変わらない |
| 絞り込み（生成日） | QRコードを生成した日で絞り込む |
| カードの表示 | 納品日、本店、ホール、商品、生成日時（`生成：2026/10/9 16:11:48` の形式） |
| 件数 | QRコード一覧の上に、`未印刷 〇件 / 表示 〇件 / 選択 〇件` を表示する |
| 一覧が空のとき | QRコードが1件もないときは「再生成したQRコードはここに表示されます。」、絞り込みで該当がないときは「条件に該当するQRコードはここに表示されます。」を、横一列で表示する |

### 3.5 ④ 印刷準備（手順7）

| 項目 | 仕様 |
|---|---|
| 絞り込み | ホール名（必須）、納品日（任意） |
| 納品日の候補 | ホール名を選ぶ前は、すべての未印刷QRの納品日を表示する。ホール名を選ぶと、そのホールの納品日に絞られる |
| 1ページあたり | 4個（2行×2列）、6個（3行×2列） |
| ボタン | 「A4 PDF作成」「全選択」「選択解除」 |
| 全選択 | 絞り込んで表示されているQRだけを選ぶ。ホール名が未選択のときは、何も起きない |
| PDF作成の条件 | 表示中で、かつ選択されているQRだけが対象 |
| 一覧が空のとき | ホール名が未選択のときは「ホール名を選択すると、該当するQRコードがここに表示されます。」、該当がないときは「条件に該当するQRコードはここに表示されます。」を表示する |

### 3.6 ⑤ 印刷済み（手順8）

| 項目 | 仕様 |
|---|---|
| 表示 | ホール名ごとにグループに分けて表示する。グループの見出しに、ホール名、件数、「このホールを全選択」を置く |
| 絞り込み | 納品日、ホール名 |
| ボタン | 「手順7に戻す」「全選択」「選択解除」 |
| 差し戻し | 選んだQRを未印刷に戻し、③・④に再表示する（再印刷に使う） |
| 削除 | 画面からの完全削除はできない。自動整理（BR-11）だけで削除される |
| 一覧が空のとき | 印刷済みが1件もないときは「印刷済みのQRコードはここに表示されます。」、絞り込みで該当がないときは「条件に該当するQRコードはここに表示されます。」を表示する |

### 3.7 ⚙ 設定

| 項目 | 仕様 |
|---|---|
| GAS・送信先 | Google Apps Script URL、転送トークン（伏せ字）、送信先Gmail。「移行設定を保存」「GAS接続テスト」 |
| 本店名 / ホール名 | 1行に「本店名,ホール名」の形式で入力し、保存する。同じ本店名に複数のホールを登録できる |
| データ管理 | 「バックアップを書き出す」「バックアップを読み込む」「全データ削除」 |
| GAS接続テスト | GASへ接続し、バージョン文字列（`logistics-system v6.0 …`）を確認する。古いバージョンの場合は、再デプロイを促す |

## 4. 業務ルール

| ID | ルール |
|---|---|
| BR-01 | `http://` または `https://` で始まる文字列だけを、URLとして保存・送信する。それ以外のQRコードは保存しない |
| BR-02 | 同じURLは、重複して登録しない。端末ごとに判定する |
| BR-03 | 読み取り結果は、追加（新規に保存）、重複（登録済み）、読み取り不可（URL以外）に分類する。同じURLを何度かざしても、1件として数える。追加したURLを再度かざしても、重複には数えない |
| BR-04 | 送信するのは、手順2で選択したURLだけ。1通のメールには最大1,000件まで入れ、超える場合は複数のメールに分ける |
| BR-05 | GASの応答で成功を確認できたURLだけを、「送信済み」に移す。応答を確認できなかった場合は、送信済みにせず、メールが届いたかの確認を促す |
| BR-06 | 送信済みの履歴は、送信から24時間で自動的に消す。送信済みのURLをもう一度スキャンしたときは、「送信済みのURLです」と表示し、手順2には追加しない |
| BR-07 | 送信済みのURLは、手順4から手順2へ戻して、再送信できる |
| BR-08 | 絞り込み中の「全選択」「付与」「選択QR削除」は、画面に表示されているQRだけを対象にする |
| BR-09 | 印刷対象は、未印刷のQRで、ホール名が付いているもの。ホール名の選択は必須 |
| BR-10 | PDFはA4縦。ページの上部にホール名と納品日を大きく表示し、QRコードの下に商品名を表示する。納品日が異なるQRは、別のページに分ける。商品名が未設定のときは、「商品未設定」と表示する |
| BR-11 | PDFを作成すると、対象のQRを「印刷済み」に移す。ホールごとに、直近2回分のPDF作成分だけを残し、それより古い印刷済みのQRは完全に削除する |
| BR-12 | 印刷済みのQRは、手順8から手順7（未印刷）へ戻して、再度PDFに含められる |
| BR-13 | 外部ライブラリを読み込めないときは、該当する機能（スキャン、PDF作成、URL一括読込）を実行せず、理由を表示する |
| BR-14 | 本店名とホール名は、設定画面のリストから選ぶ。リストを保存していない場合は、サンプルのリストを使う |

## 5. 表記

| 項目 | 形式 | 例 |
|---|---|---|
| 納品日（画面・PDF） | `YYYY/MM/DD` | `2026/10/09` |
| 日時（読み取り・送信・生成） | `YYYY/M/D HH:mm:ss` | `2026/10/9 16:11:48` |
| PDFのファイル名 | `納品資料_ホール名_納品日.pdf`。納品日が複数のときは「複数日」、未設定のときは「日付未設定」 | `納品資料_ホールA1_2026/10/09.pdf` |

## 6. 主なメッセージ

| 場面 | 表示 |
|---|---|
| 送信成功 | 送信完了：〇件（GAS応答を確認済み）。… |
| トークン不一致 | 転送トークンがGAS側(Code.gs)と一致していません。… |
| 承認未完了 | GASの承認が未完了です。… |
| 想定外の応答 | GASから想定外の応答が返りました。… |
| 応答を確認できない | 送信要求を出しましたが、GASの応答を確認できませんでした。メールが届いたか確認してください。… |
| 部品の読み込み失敗 | 必要なプログラム部品を読み込めませんでした：… |
| 登録済み | 同じURLは登録済みです。 |
| 送信済み | このURLは送信済みです。 |
| URL以外 | URL以外のQRコードです（保存しません） |

## 7. 非機能

| 項目 | 仕様 |
|---|---|
| 検出の周期 | 約0.09秒ごとに、1枚のフレームを解析する |
| カメラ | 背面カメラを優先。解像度は最大1920×1080を要求する |
| 送信のタイムアウト | 45秒 |
| 外部ライブラリ | サービスワーカーが、取得できたものをキャッシュする |
| 保存 | すべて、ブラウザのlocalStorageに保存する |
