# 物流管理作業デジタル化システム

スマートフォンで納品用QRコードを連続読み取りし、URL一覧をメールでPCへ転送します。PC側ではQRコード画像を再生成し、納品日・本店名・ホール名・商品名を付与して、納品作業で使用するQRコード一覧をPDFに出力できます。

> **現在のバージョン：v6.0**

## 主な機能

### スマートフォン作業
- カメラでQRコードを連続読み取り
- URLを抽出して保存（QR画像そのものは転送しません）
- URLの重複や、URL以外のQRコードを検出
- 読み取ったURLの一覧確認・選択・削除
- URL一覧をTXT添付メールとしてPCへ送信
- 送信済みURLの確認と、必要に応じた再送信
- 読み取り時刻・送信時刻の表示

### PC作業
- メールで受信したURL一覧を読み込み、QRコード画像を再生成
- QRコードに納品日・本店名・ホール名・商品名を付与
- 未入力項目やQRコード生成日で絞り込み
- ホール名・納品日で印刷対象を絞り込み
- 納品日ごとにページを分けたPDFを作成
- 印刷済みQRコードの管理、未印刷への差し戻し、削除
- 表示中のQRコードだけを対象とした一括選択・操作

### 動作・補助機能
- PWA対応。対応ブラウザではホーム画面に追加して利用できます
- サービスワーカーによるアプリ資材のキャッシュ
- QR読み取り・PDF作成などに必要な外部ライブラリが読み込めない場合の警告表示
- GASとの接続テスト、応答内容に基づく送信結果の確認

## 利用方法

**Webアプリ：** https://masahiromekata.github.io/logistics-system/

1. スマートフォンでWebアプリを開き、カメラの使用を許可します。
2. 「① QR連続読み込み」でQRコードを読み取ります。
3. 読み取ったURLを確認し、送信するURLを選択します。
4. 「URL送信」で設定したメールアドレスへ送信します。
5. PCでアプリを開き、受信したURL一覧を読み込みます。
6. QRコードに納品日・本店名・ホール名・商品名を付与します。
7. 「④ 印刷準備」でホール名と納品日を選択し、対象のQRコードを選んでPDFを作成します。
8. 印刷後は「⑤ 印刷済み」で印刷状況を管理します。

画面上のメニュー名・手順番号に従って操作してください。画面の幅が狭い場合、メニューは横スクロールできます。

## セットアップ

### 1. GitHub Pages

このリポジトリをGitHub Pagesで公開します。公開先は上記のWebアプリURLです。アプリの配信ファイルはリポジトリ直下に配置します。

### 2. Google Apps Script（GAS）

スマートフォンからPCへURL一覧をメール送信するには、GASのWebアプリを設定します。

1. GASプロジェクトに送信用の `Code.gs` を配置します。
2. `TRANSFER_TOKEN` に任意の共有トークンを設定します。
3. `DEFAULT_TO` に受信先メールアドレスを設定します。
4. 必要なメール送信権限を承認します（コードに `authorizeOnce` がある場合は一度実行します）。
5. Webアプリとしてデプロイし、実行ユーザーとアクセス権を設定します。
6. アプリの「共通設定」にWebアプリURLと対応するトークンを設定します。
7. アプリの「GAS接続テスト」で接続を確認します。

GASのコードを更新した場合は、デプロイ画面で**新しいバージョン**を選択して再デプロイしてください。アプリ側とGAS側のトークンは一致させてください。

> メール送信にはGoogleアカウントの権限・GASの実行制限が適用されます。設定項目やデプロイ画面の表示は、Google Apps Scriptの仕様変更により変わる場合があります。

## データの取り扱いと注意事項

- スマートフォン側の読み取りURL一覧やPC側のQRコード管理情報は、ブラウザ内に保存されます。別の端末・ブラウザとの自動同期を前提としていません。
- ブラウザのサイトデータ削除、ストレージ消去、端末故障などにより、保存データが失われる可能性があります。必要なデータは適宜バックアップしてください。
- スマートフォンから送るのはQRコード画像ではなくURL一覧です。PC側でURLからQRコード画像を再生成します。
- URL以外の内容を持つQRコードは、URL送信の対象になりません。
- カメラ機能はブラウザ・端末の対応状況に依存します。カメラを使用する際は、HTTPSで公開されたWebアプリを利用してください。
- 外部ライブラリの初回読み込みには通信が必要です。キャッシュ後も、端末やブラウザの状態によって利用できない場合があります。
- 印刷前に、納品日・本店名・ホール名・商品名およびQRコードの読み取り状態を確認してください。

## 使用ライブラリ

- [jsQR](https://github.com/cozmo/jsQR) — QRコードの読み取り
- [jsPDF](https://github.com/parallax/jsPDF) — PDF作成
- [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) — QRコード生成

各ライブラリは、それぞれの配布元のライセンスに従います。
